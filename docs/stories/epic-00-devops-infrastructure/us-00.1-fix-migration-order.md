# US-00.1: Correção da Ordem das Migrações e Remoção de Redundâncias

## 🎯 Objetivo (O que e por quê)
Resolver o erro de banco de dados no GitHub Actions: `ERROR: relation "public.user_roles" does not exist`. 
Isso acontece devido a uma migração com timestamp de 2024 tentando acessar tabelas criadas nas migrações de 2026.

## 🧠 Contexto de Expert (Visão de Marketing/Produto estratégica)
A estabilidade do pipeline de CI/CD é fundamental para a agilidade do time. Migrações mal ordenadas impedem testes automáticos e deploys seguros, gerando fricção no ciclo de entrega. Manter um padrão de timestamps (2026) evita que arquivos "fantasmas" quebrem o reset do banco.

## 📝 Requisitos Técnicos (Arquitetura, DB, Componentes)
- Verificar dependências entre migrações.
- Remover o arquivo `20240218110000_create_stripe_settings.sql` pois seu conteúdo já está contemplado e evoluído nas migrações de 2026.
- Garantir que `stripe_settings` e `stripe_events` continuem funcionando conforme as migrações mais recentes.

## ✅ Critérios de Aceite (Checklist detalhado com `[x]`)
- [x] Arquivo `20240218110000_create_stripe_settings.sql` removido.
- [x] Migrações de 2026 verificadas quanto à redundância (confirmado que 2026 cobrem tudo).
